# FAQ

## 使用

### 书架是空的，页面提示"加载遇到问题"

还没生成书库。先运行 `npm run preprocess`，再 `npm run dev` 或 `npm run build`。

### 直接打开 `/read/<id>` 是 404

- 部署在 Cloudflare Pages：检查 `dist/` 顶层有没有 `404.html`，以及 `_redirects` 有没有写 `/*`。见[路由](deploy.md#路由)。
- 部署在其他平台：检查有没有把 `/read/*` 重写到 `/index.html`。见[部署到其他静态托管](deploy.md#部署到其他静态托管)。

### 构建时报硬链接错误

`public/` 和 `dist/` 不在同一个分区，或者所在的文件系统不支持硬链接（FAT/exFAT、部分网络盘、容器挂载目录）。把仓库放到支持硬链接的本地分区上。

### 某本书的章节切错了

在覆盖表里给它指定规则，见[按书指定规则](toc.md#按书指定规则)。

### 改了覆盖表或切章规则，网站上没变化

预处理只看源文件有没有变，所以把这些书跳过了。

- 改了覆盖表：删掉那本书的 `_toc.json` 再跑预处理。
- 改了切章逻辑：把 `PIPELINE_VERSION` 加 1，见[修改切章规则](toc.md#修改切章规则)。

### 最多能放多少本书？

部署到 Cloudflare Pages 时约 9999 本：Pages 最多 20000 个文件，每本书占 2 个，单个文件不能超过 25 MiB。其他平台以各自的限制为准。

### 删了源包，书还在吗？

在。`zip-novel/` 只是待处理的输入，不是书库的名单。要删书见[删除一本书](library.md#删除一本书)。

### 站点别人能看到吗？

能。站点没有登录，拿到网址就能读、能下载整本书。只想自己看，可以用 Cloudflare Access 加一道登录。

## 为什么这样设计

### 为什么书库是硬链接进 `dist/`，而不是复制？

书库通常很大，复制一份会让磁盘占用翻倍，每次构建还要再写一遍。

### 为什么不能有 `404.html`？

Pages 只在没有 `404.html` 时，才把找不到的地址交给首页、由前端路由处理。有了它，`/read/<id>` 会直接 404。前端本来就会把未知地址跳回书架，用不着它。

### 为什么 `_redirects` 不能写 `/*`？

Pages 的重定向规则不管文件存不存在都生效。`/* /index.html 200` 会把 `/data/*.json` 和 `/books/*.txt.gz` 也返回成首页。

### 为什么压缩包里的 `.txt` 全部并入，而不是只取最大的？

以前只取最大的，为了避开 readme 和广告文件。实际书库里有多个 `.txt` 的包都是分册合集或"正文加外传"，只取最大的会丢册。现在全部并入，每个 `.txt` 是一册，见[合集包](library.md#合集包)。真有广告文件时，用覆盖表的 `order` 只列要的文件。

### 为什么大书用 zopfli，没装时也不退回 gzip？

zopfli 比 gzip 9 级再小约 8%。退回 gzip 的话，大书可能超过 25 MiB、部署不上去，所以宁可报错。

### 为什么超过 25 MiB 的书不删源包？

这本书部署不上去，之后换压缩方式重压还要用原包。

### 为什么 `books.json` 没有缩进，也不预先压缩？

去掉缩进，浏览器解析几千本的书单更快、更省内存。压缩交给 Pages 在传输时自动做。

### 为什么只有缺依赖、缺 rar 工具、覆盖表写错时才整批停下？

这些是环境或配置问题，继续跑只会每本书都报同一个错。其他错误只影响出错的那一本。

### 为什么改了切章逻辑要手动给 `PIPELINE_VERSION` 加 1？

清单只靠源文件指纹判断要不要重新处理，而改规则不会改变任何源文件。不加 1，所有书都会被跳过，日志却一切正常。

### 为什么续读能精确到段落？

进度、书签、检索跳转都记"第几章 + 章内第几个字"，不记滚动比例或字节位置，所以换字号、换设备也能回到同一段。

### 为什么 `site.config.json` 写坏了会让构建失败？

悄悄退回默认值的话，你会带着一份以为生效了的配置上线。

### 为什么 `site.config.json` 要提交进仓库？

在 Cloudflare 云端构建时，读不到它就会用默认值发布。

### 为什么主题写成 `[data-theme="..."]`，而不是 `:root[data-theme="..."]`？

这样任何元素加上 `data-theme` 属性，里面就换成那套颜色。设置面板里同时显示五个主题色块，靠的就是这个。

### 为什么像素基线只在 Windows 上有效？

应用只用系统字体，换系统或换字体，截图就会变。

### 为什么 E2E 的服务器有两个端口？

一个原样返回 `.txt.gz`，一个带 `Content-Encoding: gzip`，这样前端两种解压方式都能测到。
