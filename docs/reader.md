# 书架与阅读器

网站只有两个页面：`/` 是书架，`/read/<id>` 是阅读器。其他地址都会跳回书架。

## 书架

- 按书名、作者或拼音首字母模糊搜索。
- 按作者筛选，"加载更多"分批展开。
- 最近在读，最多 5 本。
- 章节目录弹窗：不进阅读器就能看全书目录、挑一章开读。弹窗打开时地址栏带 `?book=<id>`，按浏览器后退就关闭。

## 阅读器

- 呈现方式取决于[翻页模式](#翻页模式)：
  - 分页模式（覆盖、滑动、仿真、无动画）：正文按屏幕大小切成整页，每章从新的一页开始，章名在第一页顶部。在章末往后翻直接进入下一章第一页，在章首往前翻回到上一章最后一页。底栏右上方显示本章页码 `x / y`。
  - 滚动模式：各章首尾相接排成一条长卷，一路往下滚就读进下一章，往上滚能接着读上一章末尾。
  - 正文末尾没有"上一章 / 下一章"卡片。要直接换章，用底栏的上一章、下一章按钮、章节滑杆或目录。
  - 翻到全书第一页或最后一页再往外翻，会短暂提示"没有上一页"或"没有下一页"。
- 点屏幕中央唤出顶栏和底栏，4.5 秒后自动隐藏。它们显示时点正文其他位置只会收起，不翻页。
- 选文字：按住 600 ms 开始选择，不松手接着拖动扩大选区。鼠标拖拽和手指拖拽一样用来翻页或滚动。有选区时点一下正文只清除选区。
- 目录：卷显示为不能点的分组标题，当前章有底色。可以按章名过滤，也可以管理书签（每章最多一个）。
- 全书检索：命中词高亮，点一条跳到那一段，正文里的命中处高亮 5 秒。分页模式下跳到命中处所在的那一页。
- 地址栏的 `?ch=` 始终是当前章，跨章翻页或滚过章界时随之更新，复制链接就能分享到这一章。换章不会多出后退步骤。
- 续读：进度记到"第几章第几个字"，换字号、换设备、换翻页模式也能回到同一段。打开带 `?ch=` 的链接时，如果正是上次读到的那章，就回到原来的位置；否则从那章开头读。
- 下载整本：把正文存成带 BOM 的 UTF-8 `.txt`，文件名是书名。入口有四个：
  - 阅读器顶栏的下载图标、设置抽屉的"下载 TXT 文件"：用已加载的正文生成，不再请求服务器。
  - 书架书卡上的下载图标、章节目录弹窗的"下载整本"：先按打开这本书的同一条路径取正文（内存、离线缓存、网络依次找），再保存。没读过的书会下载一次正文并存进离线缓存，按钮上显示进度。

## 翻页模式

在设置抽屉的"翻页模式"里选，默认滚动。选择存在阅读设置里，刷新或重新打开后不变。

| 模式 | 效果 |
| --- | --- |
| 覆盖 | 当前页向左滑走，露出压在下面的下一页；往前翻时上一页从左侧盖回来。移动的页边缘带阴影 |
| 滑动 | 前后两页连在一起平移，没有阴影 |
| 仿真 | 页角卷起，透出页背面和下一页，带阴影。浏览器不支持 `clip-path: path()` 时按覆盖播放 |
| 滚动 | 不分页，跨章连续滚动 |
| 无动画 | 直接换成目标页 |

- 分页模式下左右拖动页面翻页，页面跟着手指或鼠标走。松手前最后一下是往回拖的，就取消这次翻页，停在原页。
- 系统开启了减弱动态效果（`prefers-reduced-motion: reduce`）时：
  - 覆盖、滑动、仿真都按无动画换页，拖动时页面不动，松手时直接换页或留在原页。
  - 滚动模式下点击和按键翻页直接跳到目标位置，不做平滑滚动。
  - 设置抽屉仍标出所选的模式，所选为覆盖、滑动或仿真时，下方提示"系统已开启减弱动态效果，翻页不播放动画"。
  - 阅读中改了系统设置不用刷新，下一次翻页就按新设置来。

## 点击区域

阅读区按宽、高各在 33% 和 66% 处切成九格，点哪格做什么在五种模式下都一样：

| | 左 | 中 | 右 |
| --- | --- | --- | --- |
| 上 | 上一页 | 上一页 | 下一页 |
| 中 | 上一页 | 唤出顶栏和底栏 | 下一页 |
| 下 | 上一页 | 下一页 | 下一页 |

- 滚动模式下"下一页"是往下滚一屏，原来最底下那一行（含只露出一部分的行）滚到顶端；"上一页"反过来。
- 点在按钮、链接、顶栏、底栏或面板上，只执行它们自己的动作。

## 快捷键

| 键 | 分页模式 | 滚动模式 |
| --- | --- | --- |
| `←` / `→` | 上一页 / 下一页 | 上一章 / 下一章 |
| `↑` / `↓` | 上一页 / 下一页 | 向上 / 向下滚一小段（40 px） |
| `PageUp` / `PageDown` | 上一页 / 下一页 | 向上 / 向下翻一屏 |
| `Space` / `Shift+Space` | 下一页 / 上一页 | 向下 / 向上翻一屏 |
| `Home` / `End` | 本章第一页 / 最后一页 | 本章章首 / 章末 |
| 鼠标滚轮 | 滚一下翻一页 | 正常滚动 |
| `T` | 目录 | 同左 |
| `F` | 检索 | 同左 |
| `S` | 设置 | 同左 |
| `Esc` | 关闭面板 | 同左 |

- 滚动模式下翻一屏和点击翻页一样，保留一行。滚动跨章连续，不会停在章末。
- 按住翻页键不会连续翻页。同一方向两次按键不到 0.6 秒，后一次不算；翻页动画进行中按键也不算。
- 焦点在输入框或滑杆里、按着 Ctrl/Alt/Meta、焦点在按钮上按空格时，快捷键不生效。
- 目录、检索、设置面板打开时，翻页和滚动类按键交给面板。滚动模式下 `←`/`→` 照样换章；分页模式下它们是翻页键，同样交给面板。

## 排版设置

| 设置 | 范围 | 步长 | 默认 |
| --- | --- | --- | --- |
| 字号 | 14–36 px | 1 | 19 px |
| 行高 | 1.4–2.5 倍 | 0.05 | 1.85 倍 |
| 字间距 | 0–4 px | 0.5 | 1 px |
| 版心宽度 | 600–1200 px | 20 | 820 px |
| 离线缓存上限 | 1–50 本 | 1 | 10 本 |

- 字体：系统黑体、宋体/明体、楷体/手写。
- 主题：默认明亮、复古羊皮（默认）、护眼豆绿、暗色夜间、极夜纯黑。

## 浏览器里存了什么

| 内容 | 位置 | 说明 |
| --- | --- | --- |
| 书的离线缓存 | IndexedDB `koodo_novel_cache_db`（v2）的 `books` 表 | 存下载的 `.txt.gz` 原样；按最近阅读淘汰，上限在设置里改 |
| 阅读设置 | localStorage `koodo_novel_reader_settings` | |
| 阅读进度 | localStorage `koodo_novel_progress_<id>` | 最多 50 本，超出时删最久没读的 |
| 书签 | localStorage `koodo_novel_bookmarks_<id>` | |

## 加载出错

| 页面 | 显示 | 原因说明 |
| --- | --- | --- |
| 阅读器 | "未能打开书籍"和"返回书架" | 书库里找不到这本书、暂时连不上书库、正文文件缺失或损坏、其他问题 |
| 书架 | "加载遇到问题"和"重新加载" | 找不到书库目录、暂时连不上书库、其他问题 |

排查时看浏览器控制台里以 `[load-error]` 开头的那一行，里面有出错阶段、书 id 和 HTTP 状态。
