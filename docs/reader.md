# 书架与阅读器

网站只有两个页面：`/` 是书架，`/read/<id>` 是阅读器。其他地址都会跳回书架。

## 书架

- 按书名、作者或拼音首字母模糊搜索。
- 按作者筛选，"加载更多"分批展开。
- 最近在读，最多 5 本。
- 章节目录弹窗：不进阅读器就能看全书目录、挑一章开读。弹窗打开时地址栏带 `?book=<id>`，按浏览器后退就关闭。

## 阅读器

- 按章显示。停止操作 4.5 秒后，顶栏和底栏自动隐藏。
- 目录：卷显示为不能点的分组标题，当前章有底色。可以按章名过滤，也可以管理书签（每章最多一个）。
- 全书检索：命中词高亮，点一条跳到那一段，正文里的命中处高亮 5 秒。
- 地址栏的 `?ch=` 始终是当前章，复制链接就能分享到这一章。换章不会多出后退步骤。
- 续读：进度记到"第几章第几个字"，换字号、换设备也能回到同一段。打开带 `?ch=` 的链接时，如果正是上次读到的那章，就回到原来的位置；否则从那章开头读。
- 下载整本：把已加载的正文存成 UTF-8 的 `.txt`，不再请求服务器。

## 快捷键

| 键 | 作用 |
| --- | --- |
| `←` / `→` | 上一章 / 下一章 |
| `↑` / `↓` | 向上 / 向下滚一行 |
| `PageUp` / `PageDown` | 向上 / 向下滚一屏 |
| `Space` / `Shift+Space` | 向下 / 向上翻一屏；已到章末时按 `Space` 进入下一章 |
| `Home` / `End` | 章首 / 章末 |
| `T` | 目录 |
| `F` | 检索 |
| `S` | 设置 |
| `Esc` | 关闭面板 |

- 焦点在输入框或滑杆里、按着 Ctrl/Alt/Meta、焦点在按钮上按空格时，快捷键不生效。
- 目录、检索、设置面板打开时，滚动类按键交给面板。
- `↑`、`↓`、`PageUp`、`PageDown` 到章首或章末就停住，不会换章。

## 排版设置

| 设置 | 范围 | 步长 | 默认 |
| --- | --- | --- | --- |
| 字号 | 14–36 px | 1 | 19 px |
| 行高 | 1.4–2.5 倍 | 0.05 | 1.85 倍 |
| 字间距 | 0–4 px | 0.5 | 1 px |
| 版心宽度 | 600–1200 px | 20 | 820 px |
| 离线缓存上限 | 1–50 本 | 1 | 10 本 |

- 字体：系统黑体、宋体/明体、楷体/手写。
- 主题：默认明亮、复古羊皮（默认）、护眼豆绿、暗色夜间、极夜纯黑。

## 浏览器里存了什么

| 内容 | 位置 | 说明 |
| --- | --- | --- |
| 书的离线缓存 | IndexedDB `koodo_novel_cache_db`（v2）的 `books` 表 | 存下载的 `.txt.gz` 原样；按最近阅读淘汰，上限在设置里改 |
| 阅读设置 | localStorage `koodo_novel_reader_settings` | |
| 阅读进度 | localStorage `koodo_novel_progress_<id>` | 最多 50 本，超出时删最久没读的 |
| 书签 | localStorage `koodo_novel_bookmarks_<id>` | |

## 加载出错

| 页面 | 显示 | 原因说明 |
| --- | --- | --- |
| 阅读器 | "未能打开书籍"和"返回书架" | 书库里找不到这本书、暂时连不上书库、正文文件缺失或损坏、其他问题 |
| 书架 | "加载遇到问题"和"重新加载" | 找不到书库目录、暂时连不上书库、其他问题 |

排查时看浏览器控制台里以 `[load-error]` 开头的那一行，里面有出错阶段、书 id 和 HTTP 状态。
